# Barliesque Inspector Tools - Changelog


## [1.0.4] - 2026-11-18
### Added
- Added support for InspectorButton tooltips and grouping
### Changed
- Minimum Unity version increased to 2022.3

## [1.0.3] - 2026-11-18
### Added
- Added attribute InspectorButton
- 	To implement in custom Editors, use DrawInspectorButtons() in EditorTools, EditorBase or EditorBaseGeneric

## [1.0.2] - 2026-11-18
### Added
- Added attribute ShowWithFlag
- 	Conditionally show a property in the Inspector, if a Flag is set in another property's Enum value.
